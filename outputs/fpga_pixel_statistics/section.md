### 统计口径

- 坐标统一为 `content1000_px`：GT、PT、ONNX 从含 padding 的 1280 坐标各减去 140；FPGA 保留日志原值。仅平移、不缩放，不裁剪越界坐标；约 140px 的坐标原点差异已消除。
- bbox 中心取 `((x1+x2)/2, (y1+y2)/2)`；中心、关键点 1、关键点 2 的 pixel 偏差均为相对 GT 的欧氏距离 `sqrt(dx²+dy²)`，不是单轴绝对偏差，也不把两个关键点合并为一个样本。
- 沿用当前工作表的逐图空间关联：忽略类别、以中心点欧氏距离总和最小做一对一匹配、不设距离或 IoU 门槛。保留类别错误的关联项，不再额外按关键点置信度筛选。因此下表描述“已关联预测相对 GT 的几何偏差”，不是纯粹的同类正确检测定位误差。
- 420 张正样本各有 1 个 GT，按 GT 的 `class_id` 分组，每类 20 张；不是按预测类别分组。80 张负样本没有 GT，不参加 GT 像素偏差统计。无预测的 GT 不计 0、不补任意大数，单独报告；额外预测仍保留在原工作表，但不重复增加 GT 偏差样本。
- “最小 p% 均值”：对某阶段、某指标、某统计组的有效偏差从小到大排序，取前 `k=ceil(N×p/100)` 个求算术平均，p 分别为 25、50、75、95。它不是 P25/P50/P75/P95 分位点；三个指标分别排序，入选的图片可能不同。
- 类别排序以各阶段的 **bbox 中心全量平均偏差** 为主键、从小到大；关键点指标随同列出，不单独改变类别顺序。无有效关联的类别应排末尾并标为“—”，本次 21 类均有有效关联。

### 整体结论与优先排查项

1. PT 与 ONNX 的整体定位表现接近：各自有效样本的 bbox 中心均值均为约 7.1563px；共同 402 张上的均值为 PT 7.0933px、ONNX 7.0932px。两者差值很小，不能由这组混合口径统计认定量化造成显著整体定位退化。
2. FPGA 在共同图片集上的 bbox 中心均值为 7.9534px，较 ONNX 增加 0.8602px；两个关键点均值分别增加 0.7917px、0.7759px。该差异同时包含输入预处理、推理后端、分类错误和预测关联变化，不能全部归因于 FPGA 数值计算。
3. 典型样本与全量均值差异很大：三阶段 bbox 中心最小 75% 的均值为 1.4404／1.5049／1.4991px，最小 95% 为 2.8606／2.8637／2.8873px，均明显低于全量均值。高误差尾部是主要拉高因素；这里说的是各自排序后子集的均值，不是“95%的图片偏差低于2.9px”。
4. `032.bin / aipuha_243_view_37.bin` 在三个阶段均把 GT class_id=1 关联到 class_id=2 的预测，bbox 中心偏差约 1089px。由于当前关联没有距离门槛，这个远处误检被配对，显著拉高 aipuha 类和全量均值，应按识别失败排查，不能当成正常目标的小幅坐标漂移。
5. `306.bin / rineiwa_842_view_23.bin` 的 PT、ONNX 中心偏差约 2.1141／2.2684px、类别均正确；FPGA 则为 class_id=15，而 GT 为 11，中心偏差约 325.2364px。该样本使 rineiwa 的 FPGA 类均值升至 18.9692px，值得优先检查输入路径及误识别原因。
6. moon 在三阶段的 bbox 中心类均值均最小；aipuha 均最大。类别名次受覆盖数量及个别大错误影响，不能只看小偏差均值而忽略漏检和类别错误。本批仍有历史训练 group 重叠、旧关键点标签语义及无预设业务通过阈值等限制；本节不构成独立场景泛化或完整 FPGA 精度验收通过的结论。
