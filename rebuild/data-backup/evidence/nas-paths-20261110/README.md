`EXISTS` 表示当前目录项存在；`NOT_FOUND` 表示精确路径查询返回未找到；`UNCONFIRMED` 用于权限/网络等错误。本次正式记录没有 UNCONFIRMED。路径存在不等于文件内容可完整读取或哈希正确。

## 检查边界

- 没有读取 NAS 文件内容，包括 SHA256SUMS、manifest、VERIFIED 的内容；它们只被查询是否存在。
- 没有计算 NAS 哈希、测试 zstd/TAR/ZIP、解压、复制远端资产、挂载或写入 NAS；没有连接 H200、使用 GPU 或启动服务。
- 只列指定目录的直属条目，不做共享盘递归扫描。工程集的 6,077 个数据文件、训练/量化结果内部、records/filelists 内部未逐个确认。
- 09-02 旧系统快照的新位置没有确认；相邻目录未找到同名条目不能证明备份已删除。
- Gray1 旧名 `20260922_21目标灰度` 不存在，记录中的 `20260922_21目标灰度量化数据` 存在；本轮没有执行重命名。
