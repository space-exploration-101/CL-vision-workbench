- PT SHA-256：`622cff54db472b61c85db03648b36c119f030eacbd4cd87cf5d2dda67e69d6a7`。
- ONNX SHA-256：`031def2070a1c2183e62ce5713831bc69cd50dee3a22c10d0ffaff6580d91a02`。
