# NAS、归档与清理

触发：明确范围内的备份、归档或清理。必要输入：源资产清单、目标、owner、备份时点和恢复验收标准；删除须单独确认授权覆盖。验收为内容校验、独立回读、恢复依据及未覆盖项。

先读 [BACKUPS](../topics/BACKUPS.md) 与[详细资产清单](../../platform/01_NAS备份与环境恢复.md)。以下命令在 H200 执行。

```bash
findmnt -T /mnt/ywang-nas -o TARGET,SOURCE,FSTYPE
df -h /mnt/ywang-nas
```

必须确认挂载来源为 `//10.2.26.26/902_data` 且是 CIFS，不能将本地空挂载目录当 NAS。挂载、写备份、删除须在授权范围内；已有授权不重复询问。

- 固定文件清单、数量、字节数和 SHA-256；目标不得覆盖历史快照。
- 大文件先写同文件系统 `.partial`；执行 ZIP/TAR/zstd/gzip 格式测试及 JSON/YAML 解析。
- 发布后独立回读哈希，验证引用可恢复、无 `.partial`，再记录 `VERIFIED`。
- 按实际备份时点说明范围；后增资产的详细覆盖见[01 第 3.5 节](../../platform/01_NAS备份与环境恢复.md#35-工程批次与后增资产覆盖)，不在任务卡维护第二份状态表。
- 系统备份排除 `output_data`；旧 ZIP 不自动包含后来新增的逐层 trace。
- 单项已验证、资产齐全和隔离恢复通过分开记录；FPGA 精度也不替代灾备验收。

`output_data` 默认先 dry-run：候选为直属完整 task 目录、无活动任务、所有文件连续 14 天无修改；归档验证后再保留 7 天宽限期。失败任务不自动删除，特殊策略以明确授权为准。

删除前核对解析后的完整目标路径、引用和恢复依据。Windows 使用原生 PowerShell 与精确 `-LiteralPath`，核查重解析点越界；不跨 shell 拼接删除命令。其他 owner 的源数据须有 owner 删除授权。


记录任务授权、时间、实际变更、身份与验证结果，未复核或未完成项明确标注。返回 [RUNBOOK](../RUNBOOK.md)。
