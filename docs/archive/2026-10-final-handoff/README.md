## 安全且可重复的文档验收

当前唯一执行入口：

```text
python -B tools/check_documentation_safe.py
python -B tools/check_documentation_safe.py --report <现有安全目录中的全新文件名.json>
python -B tools/tests/test_check_documentation_safe.py
```

默认只读并输出摘要；报告仅以 exclusive-create 新建，不创建目录、不覆盖文件。禁止批量发现 tools/tests 中的业务测试。旧 check_documentation.py 保留作历史实现和纯文本解析辅助；新入口不调用其旧扫描或写入逻辑。

审查发现旧工具默认读取 .tmp 索引、只检查 is_symlink 不能充分覆盖 Windows junction，链接目标和 --report 也缺乏逐层重解析点约束。新入口在任何读取前检查词法路径、解码后链接、目录范围和每层 lstat，拒绝 work、临时/依赖目录、越界、符号链接与所有 Windows reparse point；不靠 resolve 跟随链接。目录排除先于读取其内容，报告父路径同样受控。

隔离测试只针对文档维护代码。`boundary-tests.json` 保存结果：通过受控 lstat/scandir 模拟验证 junction/符号链接及不读取后代，验证编码链接、越界、work/临时/依赖阻断、报告不覆盖、锚点解析与映射不外溢；不创建真实 work 目录或业务测试数据。既有 5 个依赖链接另仅检查自身定义，不进入目标。

局限：这是静态维护校验器，不是面对并发恶意替换目录的原子安全沙箱。运行时应保持目录稳定；报告不会证明外部 URL 在线、包内所有 Markdown 完整或业务数据正确。工具只解析已有 Markdown 链接/引用及标题，不执行 Markdown 中的命令。

## 最终快照与回滚

`final-documents.zip` 保存最终受控 Markdown 集与文档维护校验器/专用测试；`final-documents.json` 列每个成员长度、SHA-256 和 ZIP 哈希。成员逐个回读通过后由 .partial 发布。它是**最终文档快照**，不是模型、数据或完整项目备份；原文/大附件仍依赖各自保全材料。最终清单与所有本阶段记录由独立 SHA256SUMS 封存。

1. 精确回滚本阶段：先核对本目录清单，再按 after.json 比较当前文件是否仍为本轮结果；已有后续修改必须先另存、标日期与哈希，不能覆盖。从 before.zip 仅恢复六份入口，旧检查器不需要恢复。
2. 新工具如需撤回，先确认没有后续引用/修改并另存，恢复旧入口也不能直接运行旧不安全扫描。保留审计，不作宽泛递归删除。
3. 回滚更早阶段时，先保存最终文档快照以及之后的新变更，再按各阶段映射和原文包逆序恢复明确文件。完整第 2 阶段备份不会自动包含之后的文档修订或新增审计，不能直接覆盖今日工作区。
4. 外部完整备份恢复前必须另获范围授权并重新核对其元数据和所需文件；本轮未重读它，不能仅凭旧 VERIFIED 推断目前仍可用。链接定义最后单独审查，不自动恢复外部依赖。
5. 历史审计程序会写旧 after/validation，不得重跑。新文档工具只输出或新建报告；本阶段 audit_final.py 是封存过程程序，不是日常入口，封存后不要重跑覆盖其结果。
