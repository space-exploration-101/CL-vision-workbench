## 回滚方法

1. 核对本目录 SHA256SUMS、before.zip 与 before.json；按 after.json 比较现有文件。若出现后续修改，先另存副本并停止覆盖，不能把 10.18 版本覆盖到 10.19 报告。
2. 按映射核对源和目标的绝对路径均在项目内、不含目录链接；确认旧位置不存在。用 PowerShell Move-Item -LiteralPath 对三份平台文档、FPGA_logs 整组和 CSV 分别逆向移动，不合并目录。
3. 从 before.zip 只恢复 after.json 中本轮实际修改的已有文件，保留未改文件及旧原始清单。包内附件已字节一致，不需要重写。
4. 本轮新增导航和版本化清单按 after.json 逐项处理，先确认没有新增引用或后续修改，再另存到本阶段回滚材料中；不使用通配符递归删除。审计记录继续保留并记明回滚。
5. 对照 before.json 校验原位置的文件身份，重新检查活跃文档引用。此方法不授权远端、GPU、删除数据或重跑任务。
