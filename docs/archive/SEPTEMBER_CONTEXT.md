## 2. 长期保留的决策

- 输入语义是合同的一部分：R-only、Gray1、net1280 与 cam2000 不可互换；看起来相同不等于数值相同。
- 从小规模功能试跑走向正式评估；smoke 仅证明流程能运行。
- 训练数据的两个关键点重合限制了旧 Pose 指标的业务解释，未来数据必须另设版本。
- 资产按模型/数据哈希、源码 commit 和完整镜像 ID 识别；同名 v1/latest 曾对应不同内容。
- 恢复优先用已验证镜像；源码、配置、数据和模型各有独立覆盖范围。
- 大文件按 .partial → 校验 → 原子发布；系统备份与任务输出归档分开。
- 09-19 的一次归档预检因 shared_data 持续写入停止，NAS 写入为 0；[停止记录](2026-09-gray1-blocked-backup-run/README.md)不是有效备份。
