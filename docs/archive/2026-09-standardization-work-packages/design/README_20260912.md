本文档集把现有的数据预处理、训练环境和量化平台连接成可复现、可审计的工程闭环。它是后续实施大纲，不代表当前服务已经具备这些能力。

## 已确认基线（2026-09-12）

- 数据预处理仓库：`/data3/ywang/yolo-gray1-data-pipeline`。
- 量化仓库：`/data3/ywang/quantitize-platform`。
- 两个仓库均有未提交修改；任何 Agent 开始开发前必须保存 `git status`、HEAD 和 diff，不得覆盖现有工作树。
- grayprep Step 0–13 已完成；推荐 CPU 配置为 `32 workers × 1 OpenCV thread`、`/data1` scratch，最终吞吐 54.7514 items/s，是初始基线的 25.93 倍。
- 训练环境的 NAS 快照已验证：`ywang-yolo-gray1-env-20260909_124030`；包含训练镜像和重建包，但不包含完整数据集或 smoke 数据。
- H200 当前没有 `/data3/ywang/yolo-pose-train-env`，后续恢复必须进入新空目录。
- 当前量化平台已有 PT 评测、量化、ONNX 评测、FPGA 测试包、FPGA 软件评测、BIN、合并和 bundle 八阶段。

## 目标架构

```text
raw batch
  -> validated dataset version
  -> preprocessing profile
  -> training run
  -> immutable model version
  -> PT/ONNX/INT8 acceptance suite
  -> FPGA/HIL validation
  -> signed release bundle
```

每个箭头都必须由机器可读 manifest、SHA-256、版本和验收结果连接，不能依赖目录名或人工记忆。

## 推荐里程碑

1. **M0 事实冻结**：完成 WP00，现有代码、镜像、NAS 备份和未提交修改均可追溯。
2. **M1 契约冻结**：完成 WP01，确定 ID、schema、颜色语义、尺寸限制和兼容策略。
3. **M2 数据与训练可复现**：完成 WP02–WP05；任意模型可追溯到数据和训练环境。
4. **M3 质量闭环**：完成 WP06–WP08；同一测试集贯穿 PT、ONNX、INT8、FPGA。
5. **M4 平台化**：完成 WP09–WP10；任务具备调度、监控、发布、归档和回滚。

## 文档使用规则

- 一个 sub Agent 一次只领取一个 WP，严格遵守该文档的范围、前置条件和验收标准。
- 涉及 GPU、运行训练/量化、重启服务、恢复大文件或写 NAS 时，必须再次取得覆盖该动作的授权。
- H200 只能 `ssh H200` 直连；不停止其他用户进程，不修改全局 Docker、驱动、内核或 APT。
- 实施结果写入 `status/WORK_BOARD.md`，证据写入各仓库约定的文档目录；本目录只保存跨仓库设计和决策。
- 总体 Agent 工作流见 `11_AGENT_WORKFLOW.md`。

## 当前扩展授权与安全边界（2026-09-12）

用户已授权后续工作流在以下边界内执行；该授权不会自动放宽共享 H200、数据覆盖、其他用户进程或全局系统配置的保护规则。

- **`/data3/ywang` 写入**：可以创建新的目录和文件，但必须先证明目标不存在；禁止覆盖、替换或清理已有内容。大文件先写任务专属 `.partial`，校验后以 no-replace 方式发布。该授权不包含在 `/data1`、NAS 或其他路径创建内容。
- **单 GPU、小于 1 小时**：只有在利用率、显存、进程及进程所有者经过持续采样确认目标 GPU 空闲后，才可使用一张 GPU。任务必须通过显式设备绑定限制为单卡；预计超过 1 小时、无法可靠估时或运行接近 1 小时时不得继续，设置硬超时并只终止本任务自己的进程。
- **镜像恢复和小规模训练**：允许恢复已验证镜像及运行小规模 workflow smoke training；恢复前校验 manifest/digest、目标为空及镜像标签冲突，任何冲突均 fail closed。训练只验证工作流，不验证模型精度，不使用完整数据集，不启动预计超过 1 小时的任务。
- **服务重启**：仅允许重启由 `ywang` 项目拥有、任务明确点名且已有健康检查/回滚路径的服务。重启前记录状态、端口、进程所有者和依赖，重启后执行健康检查；失败则停止扩展操作并保留证据。该授权不包含 Docker daemon、系统级共享服务或其他用户进程。

以下动作仍未授权：覆盖已有目录或镜像标签、写 NAS、在 `/data1` 创建目录、使用多张 GPU、停止其他用户进程、修改全局 Docker/驱动/内核/APT，以及超过 1 小时的训练或 GPU 任务。每个 Agent 任务仍须在领取单中写明精确路径、GPU ID、时限、服务名和验收命令。
