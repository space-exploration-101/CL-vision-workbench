# 旧训练环境迁移计划：压缩摘要

原计划形成于 2026-09-08/09，2026-10-18 压缩。它是当时的方案，不是当前待执行清单。完整原文在[原文 ZIP](../2026-10-documentation-consolidation/original-documents.zip)的同路径内，原哈希见[原文清单](../2026-10-documentation-consolidation/original-documents.json)。

## 原因与方案

原训练项目与大型数据属于另一位用户，直接修改会影响其工作；因此计划在 ywang 独立空间复制必要源码，用容器固化依赖，并将单通道 Gray1 的数据加载、模型、训练、推理与导出一起适配。

数据使用索引与选择清单，避免为每轮试验重复复制原始全集；本地缓存只是派生优化。每个实验记录源码、镜像、参数、输入 manifest 与输出身份，便于比较类别数量、每类采样与模型规模。

实施顺序为：只读确认 → 独立项目与源码 → Gray1 配置 → 镜像/导入烟测 → 数据清单 → 获分配 GPU 上的 1 epoch 试跑 → PT/ONNX/量化/输入回环 → 正式实验。NAS 与离线恢复另设门禁，不能用 Git 代替大型资产备份。
