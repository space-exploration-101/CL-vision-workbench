## 2. 这一系列实验在验证什么

目标是让模型在真实航天照片里找到地球、月球，少认错、少漏掉，并标出两个规定的参考位置。

实验围绕三个问题展开：

1. 用合成地球、月球图片训练，能否适用于真实照片？
2. 加入没有地球、月球的背景图片，能否减少误报，加入多少较合适？
3. 增加大尺寸地球图片，能否改善特定真实图片上的定位问题？

几个术语在本文中的含义：

| 术语 | 通俗含义 |
|---|---|
| 正样本 / 负样本 | 有地球或月球的图片 / 没有这两种目标的背景图片 |
| 训练 / 验证 / 测试 | 用来学习 / 学习过程中检查并挑版本 / 训练后检查表现 |
| 微调 | 在已有模型上用调整后的数据继续学习 |
| 一轮训练 | 将训练数据完整学习一遍 |
| 误报框 / 漏检 | 多报或错报的目标框 / 实际存在但没找到的目标；框数不等于图片数 |
| 检测综合分 mAP50–95 | 综合衡量目标是否找到、框的位置是否准确，越高越好；不是简单的正确率 |
| 关键点坐标差 | 模型参考点与人工标注参考点之间的像素距离，越小越好；定义限制见第6节 |
| `best` / `last` | 合成验证集训练指标选出的版本 / 最后一轮版本；`best` 不保证真实照片效果最好 |

## 3. 使用了哪些数据

### 3.1 用于检查真实效果：dataset2

当前版本共2736张真实图片，含1572个地球和1331个月球；一张图可能有多个目标。本系列 dataset3～8 的训练没有使用这些真实图片。

本次真实评估使用 dataset2 的全部划分：原 train 2192张、val 274张、test 270张，不是只用270张 test。沿用已有预处理和标注：750张全幅地球已缩小一半并居中补边；历史4张无效测试图已删除。

其中 Galileo 来源376张，包含348个地球、178个月球。将其从评估清单过滤后，得到2360张非 Galileo 图片，含1224个地球和1153个月球；没有删除原图。

### 3.2 基础合成数据与微调数据

dataset3 共40000张合成图片，每张一个地球或月球，两类各20000张。地球来源为 `earth_camera_20000_v10_observed_clouds`，月球来源为 `moon_camera_20000_v8_4_realstyle`。按场景组等条件隔离训练、验证和测试；表面纹理资产有意共享，因此不能当成全新真实来源的检验。

背景候选池为 `data/data4/`：5000张星空、6000张航天器，共11000张，其中原训练池8800张。背景图保留空目标标签，不新建一个“背景类别”。下表背景占比均为背景张数除以训练总张数。

## 4. 按时间梳理实验过程

### 4.1 2026-10-18～19：dataset3 基础训练

**想验证什么：** 先让模型学会识别合成图片中的地球、月球及参考点，再检查真实效果。

从官方预训练权重出发，使用dataset3训练200轮，训练 CSV 累计时间约15小时47分钟，不含所有最终验证等开销。

**结果：** 合成图上的成绩很高，但真实图片上出现背景误报、月球漏检和部分地球定位偏差。第200轮模型在完整2736张真实图片上，检测综合分84.73%，地球误报730个框、漏检193个，月球漏检214个。

合成验证集选择的 `best` 是第43轮；在历史270张真实 test 上，第43轮与第200轮的检测综合分分别为71.01%、74.18%。真实场景中的版本排序与合成验证集不一致，后续统一以第200轮作为微调起点。

### 4.2 基础模型形成后：检查背景误报原因（笔记未注明精确日期）

**想验证什么：** 模型是否把背景灰度或照片边界当成识别地球的线索？

使用第43轮模型和4张ISS月球照片，分别修改目标和背景：原图报出8个地球框、4个月球框；保留月球并把背景置黑后，地球框降为0，月球框仍为4；去掉月球只保留背景，仍报出4个地球框；整幅均匀灰色也会报出4个地球框。

**判断：** 这支持模型利用背景线索的解释，也为加入纯背景训练提供依据。范围仅限该模型和4张照片，不能解释所有后续模型的全部错误。

### 4.3 2026-10-24：dataset4，先加入10%背景

**想验证什么：** 明确教模型“这些图里没有目标”，能否减少误报？

在同一基础模型上，用4500张正样本和500张背景微调20轮。500张训练背景中有440张会被父模型误报，只从训练背景池筛选，没有用验证、测试背景选题。

**结果：** dataset4 `best` 为微调第4轮。在同一2736张真实图片、相同固定阈值下：

| 指标 | dataset3 第200轮 | dataset4 第4轮 `best` |
|---|---:|---:|
| 地球误报框数 | 730 | 93 |
| 地球漏检数 | 193 | 108 |
| 月球漏检数 | 214 | 184 |
| 检测综合分 | 84.73% | 87.52% |

误报显著减少，同时漏检也减少，支持加入背景是有效方向。在共同100张合成纯背景测试上，误报图片由基础模型的78张降到该版本的1张；dataset4第20轮为0张。这个小测试集上的0误报，不代表所有真实背景都不会误报。

### 4.4 2026-10-25：dataset5～7，比较不同背景比例

**想验证什么：** 5%、10%、20%、30%的背景比例，哪种更适合？

dataset5～8的执行队列于13:46:15启动、15:37:40结束，包含训练与原始评估。所有微调实验都分别从dataset3第200轮初始化，各训练20轮；不是dataset4训练后接着训练dataset5，也不是编号越大就一定更好。

统一比较第20轮，完整2736张真实图片上的结果为：

| 实验 | 背景占比 | 检测综合分 |
|---|---:|---:|
| dataset5 | 约5% | 87.63% |
| dataset4 | 10% | 87.76% |
| dataset6 | 20% | 88.32% |
| dataset7 | 约30% | 88.71% |

**判断：** 第20轮比较中，30%组检测综合分最高。比较各组保存的 `best`，也是dataset7最高，其第1轮版本达到91.13%。但该版本在非 Galileo 图片上的地球定位不如dataset4 `best`，在100张合成纯背景中仍有6张误报。不能把检测综合分最高解释成所有指标最好。

背景增加也使每轮训练更新次数增加；每组仅做了一次随机种子训练，因此不能认定30%是普遍最佳比例。

### 4.5 2026-10-25：dataset8，增加大地球训练图片

**想验证什么：** 特定真实地球照片表现差，是否能通过多看大地球来改善？

大地球定义为1024画布中目标框宽、高都至少640像素。dataset4的训练地球中，大地球占15.82%（356张）；dataset8提高到80%（1800张），背景仍占训练总图数的10%。它只重选已有合成样本，没有新增真实纹理或成像风格。

另用来自原dataset3对应划分的375张验证图、298张测试图做大地球专项诊断；与共同验证、测试集在同一划分内存在部分重叠，不算全新独立测试集。

**结果：** 在298张合成大地球测试中，dataset8第20轮地球K1平均坐标差2.468像素，dataset4第20轮为2.434像素；专项方案没有超过原有dataset4。在 Galileo 上也没有稳定定位改善。

dataset8第20轮在非 Galileo 的四项平均关键点坐标差均较小，但部分差距很小，同时有更多地球误报和月球漏检。因此不能据此认定整体更好，也不能据此把 Galileo 问题归因于尺寸或纹理某一个因素。

### 4.6 2026-10-25：按 Galileo 来源拆分评估并汇总

**想验证什么：** 真实集中的困难是否集中在某个来源，整体成绩是否掩盖了这种差异？

全部六组的 `best` / `last` 共12份权重完成同一2360张非 Galileo 图片评估，汇总流程结束于16:23:18；dataset4 `best` 复用此前同权重、同参数、同图片集合并校验过的结果。dataset3第43轮未补做2736张完整集评估，不拿历史270张结果代替。

| 模型版本 | 完整2736张检测综合分 | 非 Galileo 2360张检测综合分 |
|---|---:|---:|
| dataset3 第200轮 | 84.73% | 95.52% |
| dataset4 第4轮 `best` | 87.52% | 97.54% |
| dataset7 第1轮 `best` | 91.13% | 97.76% |

**结果：** Galileo是突出难点。dataset7 `best` 在 Galileo 上找到了326/348个地球，但只找到28/178个月球。地球检出有明显改善，月球严重漏检仍未解决。排除该来源会改变考题难度、提高分数，不代表模型又得到了一次改进。

dataset7 `best` 相对dataset4 `best` 的检测综合分优势，在完整集约3.61个百分点，在非 Galileo 集仅约0.22个百分点，说明来源组成会影响模型选择。

## 5. 当前结论和可选版本

本节结论适用于截至2026-10-25已保存的实验，不代表已部署或通过业务验收。

| 关注目标 | 当前候选 | 主要取舍 |
|---|---|---|
| 整体检测、月球检出、Galileo地球检出 | dataset7 `best`，微调第1轮 | 非 Galileo 地球参考点坐标差高于dataset4；100张合成背景有6张误报 |
| 地球定位并兼顾误报、漏检 | dataset4 `best`，微调第4轮 | 完整集检测综合分较低，Galileo仍困难 |
| 非 Galileo 的平均关键点坐标差 | dataset8 `last`，微调第20轮 | 定位差距小，地球误报和月球漏检更多 |
| 比较固定20轮下的背景比例 | dataset7 `last`，微调第20轮 | 检测综合分最高，但非所有定位项最佳 |

已得到较明确支持的是“加入背景可以显著减少误报”。30%比例值得继续验证；单纯增加大地球占比没有解决 Galileo 问题；目前没有一个版本在所有指标上都最优。

## 6. 理解结果时必须保留的限制

- 误报、漏检计数使用置信度阈值0.25，同类目标框一对一匹配、框重叠度 IoU≥0.5；检测综合分使用候选阈值0.001、NMS IoU=0.7。两种统计口径不同，不能互相替代。
- 推理为灰度1024、FP32、batch 4、`rect=False`，不做测试增强。表中的固定阈值计数不是标准指标文件里按最佳F1工作点给出的P/R。
- 合成数据K1是完整参考轮廓椭圆中心，K2是三维天体中心投影；真实数据K1是拟合圆盘中心，K2是框中心。真实结果是跨定义坐标差，不是严格同定义定位精度。
- 关键点均值只包含成功匹配的目标和有效标注点；漏检单独计数，不把漏掉目标的位置偏差记为0。不同模型检出的对象不同，平均值不能直接当作同一批对象上的进步。原笔记还提供了所有模型共同检出目标的对比。
- dataset2已多次用于模型比较，不能当成从未接触过的最终独立测试集。来源内连续帧也可能相关，本轮没有给出统计显著性检验。
- 每组微调只用一个随机种子，20轮相同不等于训练更新次数相同；`best` 出现较早也不足以单独证明后续训练整体过拟合。
