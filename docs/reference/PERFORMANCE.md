# 性能分析与优化

面向需要缩短运行时间的工程师。**性能**是完成指定工作所需的时间和资源；快慢只有在模型、数据、算法与硬件条件相同时才可比较。

## 当前适用的方法

1. 固定模型/数据哈希、源码、镜像 ID、输入语义和参数；先确认业务结果可复现。
2. 分阶段记录读取数据、PT 推理、量化、ONNX 推理、打包和写文件的耗时；分开记录冷启动与重复执行。
3. 同时记录 CPU、磁盘、GPU 利用率、显存峰值和进程归属。共享服务器上的单点观测不能定位瓶颈。
4. 每次只改变一个主要因素，做 A/B 对照；provider 指推理计算实际由 CPU 或 CUDA 等哪个执行后端承担。
5. 优化后验证检测指标、关键张量、BIN 与交付包，记录数值容差和资源变化。获授权后才能启动 GPU 任务或更新部署。
