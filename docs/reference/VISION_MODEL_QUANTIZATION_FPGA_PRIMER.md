# 视觉模型、量化与 FPGA 部署基础

> 适用读者：有软件工程和基础数学经验，但没有系统学习过机器学习、深度学习或图像处理的工程师。  
> 阅读目标：建立足以理解当前 21 类 Gray1 模型、定位量化精度问题并参与 FPGA 接口评审的心智模型。  
> 阅读原则：概念在使用前先定义；解释 A 依赖 B 时，先解释 B；先给全局图，再逐层深入。

> 项目状态校订：2026-10-18，依据既有报告。当前交付为权重 INT8、激活 FP16 的 weight-only；文中的激活量化/标定知识是一般方法，不表示当前模型存在激活 QDQ。零基础读者可先读[交接手册](../HANDOFF.md)。

## 1. 先看全局

当前系统处理的是一个姿态检测任务：输入一张灰度图，输出目标类别、边界框和两个关键点。

```text
原始图像
  -> 确定的灰度与几何预处理
  -> 神经网络
       Backbone：从像素中提取层次化特征
       Neck：融合不同空间尺度的特征
       Head：产生框、类别和关键点预测
  -> 置信度过滤与 NMS
  -> 最终检测结果
```

模型部署又增加了一条数值与硬件链路：

先定义图中会出现的名称：

- **PyTorch 模型**：当前训练框架保存的模型和权重；
- **ONNX**：用跨框架计算图描述模型的交换格式；
- **FP16**：用 16 bit 浮点数表示数值；
- **量化**：把浮点数近似映射到更低成本的整数或其他有限精度表示；
- **QDQ**：在 ONNX 图中显式表示量化和反量化的一对算子，后文详细解释；
- **FPGA**：可以按项目需求配置数据通路和并行计算结构的可编程硬件；
- **NMS**：删除同一目标重复预测框的后处理方法，后文详细解释。

```text
PyTorch 浮点模型
  -> FP16 ONNX
  -> 当前 weight-only 量化模型
  -> 权重、参数和测试输入 BIN
  -> FPGA 算子与存储布局
  -> FPGA 输出
  -> 与软件基线比较
```

这里有三类不同问题：

1. **模型问题**：网络是否学会识别目标。
2. **数值问题**：FP16、INT8 或 INT16 近似是否改变结果。
3. **接口问题**：shape、布局、字节序、对齐和后处理是否一致。

三类问题可能表现出相似症状，例如“没有检测结果”，所以必须分层验证，不能混在一起调试。

## 3. 图像如何进入程序

### 3.1 图像、像素和通道

数字图像是一个规则网格，每个位置保存一个或多个数值。

- 灰度图每个像素通常只有一个强度值。
- RGB 图每个像素有红、绿、蓝三个值。
- `uint8` 灰度通常使用 `0..255` 表示从黑到白。

当前模型使用真正的单通道 Gray1，而不是把灰度值放在三通道图像的某一个通道中。

### 3.2 张量

张量可以理解为多维数组。图像送入网络时通常增加 batch 和 channel 维度。

```text
[N, C, H, W]
```

- `N`：一次处理多少张图；
- `C`：通道数；
- `H`：高度；
- `W`：宽度。

当前输入：

```text
[1, 1, 1280, 1280]
```

表示一次输入 1 张、1 通道、1280×1280 的图像。

### 3.3 Shape、layout 和 dtype

这三个概念必须分开：

- **shape**：每个维度有多少元素；
- **layout**：这些维度和元素按什么顺序排列；
- **dtype**：每个元素如何表示，例如 `uint8`、`float16`、`int8`。

两个文件即使字节数相同，只要 layout 或 dtype 不同，解释出的数值就可能完全不同。

> **量化与 FPGA 重点**  
> shape 正确不代表输入正确。还必须同时确认 layout、dtype、归一化、通道语义、字节序和 padding。

## 4. 模型、参数、训练和推理

### 4.1 模型是一个可调函数

可以把神经网络写成：

```text
y = f(x; w)
```

- `x` 是输入图像；
- `y` 是预测结果；
- `w` 是大量可学习参数，例如卷积权重；
- `f` 是网络结构规定的计算过程。

### 4.2 训练

训练时有人工标签。网络先预测，再计算预测与标签之间的误差，最后调整参数，使未来误差更小。

```text
输入 -> 预测 -> 损失函数 -> 反向传播 -> 更新参数
```

反向传播本质上是链式法则的工程化应用：计算每个参数对最终误差产生了多大影响。

### 4.3 推理

推理时参数已经固定，只执行前向计算：

```text
输入 -> 网络 -> 预测
```

量化和 FPGA 部署主要改变推理时的数值表示与执行方式，不应该改变模型希望表达的函数。

## 5. 线性、非线性与激活函数

### 5.1 线性变换

线性变换的核心形式是加权求和：

```text
y = Wx
```

加入 bias 后是仿射变换：

```text
y = Wx + b
```

卷积对输入也是一种线性变换，只是它具有局部连接和权重共享结构。

### 5.2 为什么纯线性层不够

多个线性层可以合并：

```text
W3(W2(W1x)) = (W3W2W1)x
```

因此，如果整个网络只有线性计算，叠很多层仍然等价于一个更大的线性变换。它不能表达需要多段边界或条件组合的关系。

XOR 是一个简单例子。四个输入点中，正例位于对角位置，无法用一条直线把正负例分开。加入非线性后，网络可以组合出多条边界。

### 5.3 激活函数

激活函数是放在线性变换之后的非线性函数：

```text
x -> 线性变换 -> 激活函数 -> 下一层
```

直觉上，它像一个连续可调的门，让某些特征通过、压低另一些特征，从而表达“在某些条件下才响应”。

当前模型大量使用 SiLU：

```text
SiLU(x) = x * sigmoid(x)
```

较大的正值基本通过，较大的负值被压低，零附近平滑变化。

> **量化与 FPGA 重点**  
> 激活函数会改变激活值分布。SiLU 输出包含小幅负值，量化范围、zero-point、舍入和硬件近似都可能影响结果。

## 6. 卷积为什么适合图像

### 6.1 局部性

图像中的边缘、角点和纹理首先表现为邻近像素之间的关系。卷积只查看一个小窗口，例如 `3×3`，符合这种局部结构。

### 6.2 权重共享

同一个边缘可能出现在图像任何位置。卷积核在整张图上重复使用同一组权重，不必分别学习“左上角的竖线”和“右下角的竖线”。

### 6.3 卷积核和特征通道

一个卷积输出通道可以理解为一个可学习的局部模式检测器。训练后，不同通道可能对不同方向的边缘、纹理、弧线或更复杂结构敏感。

浅层常形成较简单的模式，后续层再组合这些响应：

```text
像素
  -> 边缘和亮暗变化
  -> 角点、弧线和纹理
  -> 局部形状
  -> 目标部件
  -> 与类别相关的整体结构
```

这是一种常见直觉，不代表每个通道都能被人类清楚命名。

### 6.4 Kernel、stride 和 padding

- `k3`：卷积核大小为 `3×3`；
- `s1`：窗口每次移动 1 格；
- `s2`：窗口每次移动 2 格，输出宽高通常减半；
- `p1`：输入四周补 1 圈，使 `3×3、s1` 卷积通常保持宽高。

### 6.5 输入和输出通道

卷积权重常见 shape：

```text
[C_out, C_in, K_h, K_w]
```

当前模型第一层逻辑权重是：

```text
[80, 1, 3, 3]
```

即从 1 个灰度通道生成 80 个特征通道。

> **量化与 FPGA 重点**  
> ONNX 通常保存逻辑 shape，FPGA 可能要求通道按 32 对齐。逻辑 `[80,1,3,3]` 和物理存储 shape 不能混为一谈。

## 7. 分辨率、深度、感受野和语义

### 7.1 空间分辨率

特征图的 `H×W` 表示网络在空间上保留多少网格位置。`160×160` 比 `20×20` 能记录更精细的位置差异。

### 7.2 网络深度

深度表示一个特征经过了多少层变换。离输入近叫浅层，经过许多模块后叫深层。

深度和分辨率经常相关，但不是同一概念。经过 Neck 融合后的 P3 仍是高分辨率特征，却已经包含深层信息。

### 7.3 感受野

感受野是某个特征位置能够受到原图中多大区域影响。连续卷积和下采样会扩大感受野。

stride 64 表示相邻 P6 网格点在原图上相隔约 64 像素，但一个 P6 特征点的实际感受野通常远大于 64×64。

### 7.4 语义

语义在视觉模型中表示“对当前任务有意义的结构”，不要求能转换成一句自然语言。

以地貌灰度图为例：

| 层次 | 可能表达的内容 |
|---|---|
| 浅层 | 明暗边缘、边缘方向、亮点、阴影边界、噪声纹理 |
| 中层 | 弧形、脊线交叉、局部凹陷、成组纹理 |
| 深层 | 完整地标形状、部件关系、目标与阴影的组合、类别差异 |

深层语义通常对小幅亮度变化和局部噪声更稳定，但空间位置更加粗糙。

## 8. BatchNorm、残差和复合模块

### 8.1 BatchNorm

BatchNorm 在训练时根据一批数据调整中间特征的均值和尺度，使优化更稳定。推理时它使用已经固定的统计量，本质上可写成每个通道的仿射变换。

部署时经常把 Conv 和 BatchNorm 融合，减少运行算子。融合会改变卷积权重和 bias 的实际数值分布。

### 8.2 残差连接

残差连接把输入直接加到模块输出：

```text
y = F(x) + x
```

网络只需学习相对输入的修正量，也给梯度提供更短的传播路径，因此更容易训练深层网络。

### 8.3 Conv、C2f、C2 和 SPPF 的层级

YOLO 总图中的方框通常是复合模块：

```text
顶层模块编号：0、1、2...
模块类型：Conv、C2f、C2、SPPF...
模块参数：k3、s2、n3...
模块内部算子：Conv2d、BatchNorm、SiLU、Split、Concat、Add...
```

- `Conv` 通常包含 `Conv2d -> BatchNorm -> SiLU`；
- `C2f` 使用拆分、多条路径、多个 Bottleneck 和拼接来复用不同深度的特征；
- `C2` 与 C2f 思想相近，内部连接方式略有不同；
- `SPPF` 连续进行最大池化，低成本引入不同范围的上下文；
- `n3`、`n6` 表示内部模块重复 3 次或 6 次，不是数值位宽。

## 9. 从分类到检测和姿态估计

### 9.1 分类

分类回答整张图属于什么类别。

### 9.2 目标检测

检测还要回答目标在哪里，通常输出：

- 类别分数；
- 边界框位置；
- 预测置信度。

边界框常用中心点、宽高，或者左右上下距离表示。

### 9.3 姿态估计

姿态模型在检测基础上增加关键点。当前模型每个目标有两个关键点，每个关键点包含：

```text
x, y, visibility
```

因此关键点分支有 `2×3=6` 个逻辑输出。

### 9.4 候选、IoU 和 NMS

网络会产生大量候选预测。IoU 衡量两个框重叠程度：

```text
IoU = 交集面积 / 并集面积
```

NMS 按分数保留较可信的框，并删除与其高度重叠的同类框。NMS 是网络输出之后的后处理，不是卷积网络本身。

## 10. 多尺度检测的来源

### 10.1 图像金字塔

传统视觉会把同一张图缩放成多个尺寸，再分别检测。高分辨率适合小目标，低分辨率适合大目标，但重复处理整张图成本很高。

### 10.2 网络内部的特征金字塔

卷积网络本身就产生多个分辨率的特征图，因此可以直接在不同层上预测。

SSD，即 Single Shot MultiBox Detector，是早期有代表性的一阶段多尺度检测器。它在一次前向计算中，直接从多个特征图预测类别和框。直觉来自滑动窗口、默认框和图像金字塔。

SSD 的高分辨率浅层特征语义较弱，小目标仍可能难以识别。这推动了后续的特征融合结构。

## 11. Backbone、Neck 和 Head

### 11.1 Backbone

Backbone 是通用特征提取器。它逐步下采样并增加特征通道，把像素转换成层次化表征。

```text
像素 -> 局部结构 -> 部件 -> 整体目标结构
```

当前模型的 0–11 层属于 Backbone。

### 11.2 Neck

Neck 融合不同分辨率和不同深度的特征，解决以下矛盾：

- 浅层位置精细，但对类别理解较弱；
- 深层类别语义更强，但位置较粗。

当前模型的 12–29 层属于 Neck。

### 11.3 Head

Head 把融合后的特征翻译成任务输出。当前 Pose Head 包含：

- bbox 分支；
- 21 类分类分支；
- 2 个关键点分支。

当前模型的第 30 层是 Head。

## 12. 特征融合、旁路、U-Net、FPN 和 PAN

### 12.1 相加和拼接

相加要求 shape 一致，计算简单，但会立即混合两种来源。

Concat 沿通道方向保留两边信息：

```text
[640, 40, 40] + [640, 40, 40]
-> [1280, 40, 40]
```

后续卷积再学习如何筛选和融合。

### 12.2 旁路和跳跃连接

旁路把较早的特征直接送到较后的模块，绕过中间的压缩路径。它既能保留空间细节，也能缩短梯度传播路径。

### 12.3 U-Net

U-Net 包含压缩路径和恢复路径。恢复分辨率时，它把相同尺寸的浅层特征直接拼接回来，因此特别适合需要精确像素位置的分割任务。

### 12.4 FPN

FPN 将深层低分辨率特征上采样，再与相同分辨率的浅层特征融合：

```text
深层语义 -> 高分辨率尺度
```

Upsample 本身不会恢复丢失的细节。细节来自 Backbone 的浅层旁路。

### 12.5 PAN

PAN 在 FPN 基础上增加自底向上的聚合：

```text
增强后的高分辨率特征 -> 再次下采样到深层尺度
```

“自顶向下”和“自底向上”描述的是特征金字塔层级，不是流程图箭头在纸面上的方向。

当前模型中：

```text
12–20：20×20 -> 40×40 -> 80×80 -> 160×160
21–29：160×160 -> 80×80 -> 40×40 -> 20×20
```

## 13. YOLO 的思想来源

在进入历史之前，还需要三个检测术语：

- **Anchor**：预先给每个网格位置放置若干参考框，网络预测相对参考框的修正量；
- **Anchor-free**：不依赖预设参考框，直接从位置或点预测目标边界；
- **DFL**：Distribution Focal Loss 的简称，把边界距离表示为离散位置上的概率分布，再从分布得到连续距离。相比直接回归一个数，它能表达更细的定位信息。

第一代 YOLO 在 2015 年公开，2016 年发表。它把检测统一成一次网络前向计算，直接从整张图预测框和类别。

现代 YOLO 不是由单一理论推导出来的，而是吸收了多条技术路线：

- 生物视觉中的局部感受野启发；
- 卷积的局部性与平移等变性，即输入结构发生平移时，特征响应也倾向于相应平移；
- 反向传播和梯度优化；
- 残差网络；
- 图像与特征金字塔；
- SSD 式一阶段多尺度检测；
- FPN/PAN 双向特征融合；
- CSP/C2f 式部分连接和高效梯度路径；
- anchor-free 检测；
- DFL 边界框分布预测；
- IoU 损失和 NMS。

当前使用的 YOLOv8 Pose 结构来自这一长期演进，而不是原始 YOLOv1 的直接复制。

## 15. 数值表示与量化

### 15.1 浮点和整数

FP32、FP16、INT8 和 INT16 的区别不只是文件大小：

- 浮点数使用指数和尾数，可以覆盖很大范围；
- 整数位宽固定，表示范围有限；
- 位宽越小，存储和计算通常越便宜，但可表示的数更少。

### 15.2 量化映射

常见整数线性量化：

```text
q = clamp(round(x / scale) + zero_point)
x_approx = scale * (q - zero_point)
```

- `x`：原浮点值；
- `q`：量化后的整数；
- `scale`：一个整数步长代表多少浮点范围；
- `zero_point`：浮点 0 对应哪个整数；
- `round`：舍入；
- `clamp`：超出整数范围时饱和到边界。

量化误差主要来自舍入和饱和。

### 15.3 对称和非对称量化

对称量化通常令 `zero_point=0`，实现简单，适合正负大致对称的权重。

非对称量化允许非零 zero-point，更充分利用偏向一侧的数值范围，但硬件必须正确处理零点偏移。

### 15.4 Per-tensor 和 per-channel

- per-tensor：整个张量共用一个 scale；
- per-channel：不同输出通道使用不同 scale。

卷积权重各通道的范围可能相差很大，per-channel 通常精度更好，但硬件要保存和索引更多 scale。

### 15.5 权重、激活和累加器

这三者可以采用不同位宽：

```text
权重 INT8
激活 INT16 或 FP16
乘加累加器更宽
输出再缩放
```

因此“模型是 INT8”通常过于含糊。必须分别说明 W、A、accumulator 和 I/O。

> **量化与 FPGA 重点**  
> 当前软件交付为权重 QInt8、激活 FP16，无激活 QDQ；旧激活 QInt16 试验已被替代。BIN 存储格式、ONNX 图语义和 FPGA 内部算术是三个不同层次，必须分别确认。

## 16. 标定、MinMax、Entropy 和 QDQ

### 16.1 为什么需要标定

本节解释激活静态量化的一般方法；当前 weight-only 交付没有激活量化。激活值取决于输入图片。激活静态量化需要用一批有代表性的标定图运行网络，观察每层数值范围，再确定 scale 和 zero-point。

标定集用来确定量化范围，测试集用来评价精度，两者职责不同。

### 16.2 MinMax

MinMax 记录观测到的最小值和最大值，把整个区间映射到整数范围。

优点是直观，缺点是少量异常大值可能拉宽范围，使大多数普通值挤在较少的整数刻度中。

### 16.3 Entropy

Entropy 方法统计数值直方图，尝试寻找一个截断范围，使原始分布与量化后分布的信息差异较小。它可能主动舍弃极少数离群值，以提高主体区间的分辨率。

Entropy 不保证总是优于 MinMax。两者必须使用相同数据和评价口径实测。

### 16.4 QDQ

QDQ 指 ONNX 图中的：

```text
QuantizeLinear -> DequantizeLinear
```

它显式描述“这个张量先按某组参数量化，再恢复到浮点近似值”。QDQ 可用于模拟量化误差，也便于运行时识别可量化算子。

QDQ 模型的输入输出仍可能是 FP16。看到 FP16 I/O 不代表内部没有量化。

## 17. 为什么量化可能导致精度下降

常见原因包括：

- 标定数据不能代表真实分布；
- scale 被异常值拉大；
- 激活位宽、signedness 或 zero-point 配置错误；
- per-channel axis 用错；
- 某些敏感算子不适合相同量化方式；
- 预处理与训练不一致；
- QDQ 插入位置不符合预期；
- 舍入和饱和规则与目标硬件不同；
- 输出解码或 NMS 把数值误差放大；
- 配置看似设置成功，实际被 API 忽略。

9 月 19 日的历史试验中，PT 与 FP16 ONNX 对齐而激活 QDQ 精度下降，因此当时应检查其配置、范围和逐层误差。9 月 20 日已恢复 weight-only 路径，462 张检测指标与 PT 一致；当前未完成项是量化模型全量回归和 FPGA 实机验收，见[当前报告](../class-21/reports/current/README.md)。

## 18. FPGA 部署需要增加的认识

### 18.1 ABI

ABI 是生产者和消费者之间的二进制合同。对于模型部署，它至少包括：

- tensor shape 和 layout；
- dtype、signedness 和字节序；
- 通道、行和块的对齐；
- scale、zero-point、bias 和 BN 参数布局；
- 文件顺序、offset、长度和版本；
- 输出通道含义。

### 18.2 逻辑 shape 与物理布局

模型逻辑上可能只有 1 个输入通道，但 FPGA 阵列一次处理 32 个通道，因此物理存储可能补齐到 32。

```text
逻辑输入通道：1
物理输入 lane：32
有效 lane：1
padding lane：31
```

补零位置和权重排列必须完全一致，否则数值有限、程序不报错，结果仍可能全部错误。

### 18.3 Tin/Tout 和 tiling

Tin/Tout 表示硬件每个计算块并行处理的输入/输出通道数量。当前软件按 32 对齐。

这会影响：

- 权重重排；
- 通道 padding；
- DMA 长度；
- 层与层之间的 buffer 布局；
- concat 和 split 的实现。

### 18.4 软件参考与硬件实现

需要建立逐级参考：

```text
PT
-> FP16 ONNX
-> 当前 weight-only ONNX
-> 软件 BIN roundtrip
-> FPGA 单层
-> FPGA 整网
-> 后处理
```

每一级只和紧邻的上一级比较，才能定位第一个产生差异的位置。

## 20. 常见误解

| 误解 | 更准确的理解 |
|---|---|
| 层越深只是看到更多像素 | 还经过更多非线性组合，抽象程度也更高 |
| 高分辨率就是浅层 | Neck 可以生成包含深层语义的高分辨率特征 |
| Upsample 能恢复细节 | 它只放大网格，细节主要来自浅层旁路 |
| 输出 finite、非零就说明正确 | 这只能排除部分结构故障，不能证明精度 |
| QDQ 输入输出是 FP16，所以没有量化 | 量化可能发生在图内部 |
| INT8 模型表示所有数据都是 INT8 | 权重、激活、累加器和 I/O 可能各不相同 |
| 软件精度通过就能部署 FPGA | 还要验证硬件支持的数值与二进制合同 |
| P1/P2 不在 Head，所以不存在 | 它们存在于 Backbone，只是不直接做检测预测 |

## 21. 推荐调试顺序

```text
1. 冻结模型、数据和预处理身份
2. 验证 PT 基线
3. 验证 FP16 ONNX 与 PT 等价
4. 验证 148 个权重反量化节点、逐通道参数及无激活 QDQ
5. 比较 weight-only 与 FP16 的逐层数值
6. 验证权重、BN、scale 和输入 BIN roundtrip
7. 验证 FPGA 单层与软件参考
8. 验证 FPGA 整网输出
9. 验证 NMS、类别表和坐标映射
10. 执行完整 test 回归
```
