# 运维资料维护

继承 [专题规则](../AGENTS.md)。执行前按 [RUNBOOK](../../agent/RUNBOOK.md)选择任务卡。runs 是证据，prompts 是模板，tools 是工具；任何一个都不扩大当前用户授权。

平台共用的新导航放 [docs/operations](../../operations/README.md)，不在此扩写平台事实表；原任务证据保持原位置。文档整合按[任务卡](../../agent/tasks/DOCUMENTATION.md)执行。

报告记录精确路径、资产身份、校验方法与未完成项。对已发布报告补充后续状态时保留原观察日期，不把本地整理描述为远端变更。
