# 运维与执行资料

运维负责服务、文件与恢复过程；实验报告负责模型效果，两者的“通过”不能互相替代。

平台共用的诊断、服务与备份路线从[日常平台运维](../../operations/README.md)进入。本目录保留与模型任务有关的模板、工具和必要证据入口；已有平台运行证据仍按原路径保存，不为职责分层迁移历史任务包。

- [prompts](prompts/README.md)：专用模板保留原位；所有模板由 [AGENT_GUIDE](../../AGENT_GUIDE.md#统一模板入口)统一索引，模板不是执行授权。
- [tools](tools/README.md)：归档与独立校验脚本保留原位，逐项身份只在[根工具总索引](../../../tools/README.md)维护。
- [runs](runs/README.md)：按适用范围查原始凭证，不是执行入口；过期步骤与后续替代关系先读[归档摘要](../../archive/2026-10-operations-history/README.md)。

当前运行结论从[H200 环境](../../platform/02_H200训练测试推理与量化运行环境.md)读取；历史过程只用于追溯。
