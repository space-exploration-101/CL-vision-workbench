# 归档、恢复与新数据任务模板

面向任务发起者填写；编排于 2026-10-19，不代表现场验收。由[统一模板入口](../../../AGENT_GUIDE.md)索引，原路径保留。执行先读根 [AGENTS](../../../../AGENTS.md)、[CONTEXT](../../../agent/CONTEXT.md) 与 [RUNBOOK](../../../agent/RUNBOOK.md)，只展开对应卡片。

本模板不保存会重复过时的资产状态表。当前覆盖见[BACKUPS](../../../agent/topics/BACKUPS.md)，详细身份见[平台 01](../../../platform/01_NAS备份与环境恢复.md)，模型见[MODEL_BASELINE](../../../agent/topics/MODEL_BASELINE.md)。历史版本原文已纳入整理前完整副本。

## 1. 先填写共同信息

使用[共同骨架](../../../AGENT_GUIDE.md#共同骨架)，补齐精确源/目标、owner、快照格式/版本、恢复目标及是否允许删除。本页只提供归档场景的追加字段，不复制通用骨架；实际步骤、门禁与验收按 [BACKUP](../../../agent/tasks/BACKUP.md)，完整恢复再读[恢复方法](../../../reference/RECOVERY.md)。

## 2. 按目标追加要求

| 目标 | 追加要求 |
|---|---|
| 只读缺口审计 | 核对源 commit、镜像 ID、真实 CIFS 来源、备份清单与后加产物；输出缺口，不创建备份或清理源文件 |
| 增量归档 | 填写源清单、快照版本、新目标、写入授权和资源预算；按 BACKUP 门禁执行，不覆盖旧快照 |
| 独立校验 | 指定目标副本、源清单、允许读取的完整范围和验收口径；失败保留现场 |
| 隔离恢复 | 指定资产版本、隔离目标、允许的 CPU/GPU/服务测试及恢复验收范围；保留原环境 |
| 新数据版本 | 更新地标点、保持 21 类顺序、改用新来源；新 ID 与 manifest，保持旧数据不变，独立验收后再训练 |

## 3. 必须保留的边界

- 当前覆盖、恢复状态和缺口只按[详细事实来源](../../../platform/SOURCES.md)引用证据日期；不要从旧提示词推断缺失资产。
- 文件存在、资产校验、隔离恢复通过是不同状态，不相互替代。
- 系统备份排除 output_data，任务输出单独归档；后加文件不自动进入旧包。
- 清理须有明确范围、已验证副本与恢复依据；其他 owner 的源数据还需要其授权。
- 软件回环、逐层参考与真实 FPGA 精度分别验收；全量回归结论须回到原报告，不由模板维护。
- 不保存/输出明文密码，不从旧提示词继承操作授权。
