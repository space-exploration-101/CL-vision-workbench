# 专用模板存放位置

统一选择入口是 [AGENT_GUIDE](../../../AGENT_GUIDE.md#统一模板入口)。本目录只保留现有专用模板，不复制通用模板，不增加单模板目录。模板回答怎样描述任务；[任务卡](../../../agent/tasks/README.md)回答执行步骤与门禁。

[归档与恢复模板](21类Gray1_NAS归档与恢复资料精简_AGENT提示词.md)用于填写目标、资源、允许操作和验收。它不是自动执行的指令。

先读根 [AGENTS](../../../../AGENTS.md) 和 [RUNBOOK](../../../agent/RUNBOOK.md)，只展开任务需要的卡片。当前备份范围以[平台 01](../../../platform/01_NAS备份与环境恢复.md)为准，不从旧提示词推断缺失资产。
