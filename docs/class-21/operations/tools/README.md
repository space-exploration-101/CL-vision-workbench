# 归档工具

这两个参数化脚本列为可复用工具候选，原路径和实现保留；本次仅补导航，未重新运行验证。与冻结实验脚本的分工见[工具身份索引](../../../../tools/README.md#工具身份与使用入口)。

具体脚本、用途、适用版本、风险与授权只在[根工具总索引](../../../../tools/README.md#工具身份与使用入口)逐项维护；这里不建立第二份工具清单。

参数化不等于任意版本已兼容：快照格式、Linux 外部程序、CIFS 挂载、源/目标范围和链接必须另行审查，尤其独立校验会检查 nas-root 下的 partial。两者均未在本阶段执行，不凭文件名保证无副作用或遍历安全。

执行前核对参数、源路径、NAS 挂载与目标目录，按[备份任务卡](../../../agent/tasks/BACKUP.md)确认授权和验收。工具存在不代表当前源数据可删除，历史完成记录见[backup](../runs/backup/README.md)。
