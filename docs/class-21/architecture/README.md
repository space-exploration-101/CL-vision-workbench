# 网络架构与硬件接口

“网络”是模型中逐层进行数值计算的结构；“接口合同”约定输入、输出和硬件数据布局。没有相关背景时先读[基础知识](../knowledge/01_YOLO_Gray1与量化基础.md)。

- [网络结构与 FPGA 适配说明](Pose21_Gray1网络结构与FPGA适配说明.md)：工程师阅读的层次、算子、输出和硬件问题。
- [机器可读合同](pose21_gray1_fpga_contract.yaml)：供工具读取的参数与待确认字段。
- [逐层实验依据](../reports/current/20260925_Pose21_Gray1_单图逐层输入输出导出试验.md)：固定单图软件参考。

合同中的待确认值不能作为硬件验收结论，数值需与具体模型身份相匹配。
