# 地理特征点定位：量化平台 KPTS 评价升级计划

版本：v0.6，2026-10-29。状态：**候选 500 张 A/B/C/D 作业已完成数值运行；全量计数与指标说明展示已修正；业务与硬件验收仍待完成**。

本计划依据本轮明确的地理特征点定位需求，以及 2026-10-27 的 500 张 PT 对照结果制定。第 1–12 节保留设计、评审项和问题定位证据；第 13 节记录首轮 PT 实施，第 14 节记录平台评价指标发布，第 15 节记录指标说明与 Web 更新，第 16 节记录存储切换，第 17 节记录真实结果展示与提示修正。尚未确认的业务语义和精度门槛仍是建议，不因数值评估落地而视为业务验收通过。

## 1. 背景与目标

任务目标是在地球表面识别具有稳定地理含义的特征，并给出该地理位置在图像中的像素坐标。像素坐标记为 `(x, y)`；本计划中原点位于图像左上，x 向右、y 向下。

检测框（bbox）表示图像中一个地标区域的范围。框中心是几何计算得到的位置，会随可见范围、裁切、视角和框的标注方式变化，不一定对应同一个实际地理位置。因此，框检测正确、框中心误差较小，仍不能直接证明地理特征点定位准确。

本轮改进是把具有明确身份的边缘拐点、交汇点、端点等标注为关键点（KPTS），由模型直接预测这些点的坐标。单纯在一条平滑边缘上任意选点，仍缺少跨视角的一致身份；每个关键点应有可复核的定义和标注示例。

平台升级后的目标是：**用框识别目标及关联实例，用 K1/K2 衡量地理特征点的像素定位能力，并用同一套标准比较量化前后变化。**

本计划验收的是图像内像素定位。把像素坐标进一步转换为经纬度或地面距离，还需要相机标定、姿态和地理配准等条件，不能仅凭本计划中的像素误差作出米级精度结论。

## 2. 必须区分的三种版本

1. **模型和数据语义版本**：旧版以框中心或近似中心作为定位代理；新版面向有明确地理身份的 K1/K2。网络都有两个关键点，不代表这两个点的业务含义相同。
2. **GT 解析版本**：GT 是人工标注真值。历史平台会在 K1 可见时用 K1 替代 bbox 中心；标准 YOLO Pose 标签则分别保存 bbox 和关键点，两者不能互相替代。
3. **评估版本**：旧平台主要统计框级指标；本轮拟以关键点定位指标为主，并保留检测指标辅助解释漏检、误检和关联失败。

修正 GT 解析可能改变同一模型的统计结果，但不改变模型本身。更换业务定位目标也不等于可以把旧指标和新指标直接横向比较。

现有冻结模型身份继续由[模型基线](../../agent/topics/MODEL_BASELINE.md)维护。本次候选模型和 500 张数据是独立对象；本计划不把候选模型直接登记为新的冻结基线。

## 3. 新老版本在框与关键点上的差异

| 项目 | 旧版：框中心代理定位 | 新版目标：语义关键点定位 |
|---|---|---|
| 业务输出位置 | 目标框中心，或把接近中心的关键点作为代理 | 具有明确地理身份的 K1/K2 像素坐标 |
| bbox 的标注与选择 | 关注地标区域，框中心承担定位意义 | 仍按地标区域规范标框；框用于检测、NMS 和实例关联 |
| 关键点位置 | 旧版数据中两个点重合、多数接近框中心，详见知识库 02 | 可位于有明显特征的边缘或点；不要求位于框中心，也不要求 K1/K2 重合 |
| 框中心与 KPTS 的关系 | 旧平台解析对两者存在耦合 | bbox、K1、K2 分开解释、分开保存，修改 KPTS 不改变 GT 框 |
| 预测框筛选 | 按模型置信度、类别和 NMS 处理 | 保留该流程；不因更重视 KPTS 而只挑靠近 GT 的预测框 |
| 多目标关联 | 同类目标的一对一框匹配 | 固定阈值像素评价首轮保留相同关联规则，点位在对应目标内按 K1/K2 身份比较 |
| 主要评价 | 检测 P/R/F1、框中心误差 | 分 K1/K2 定位误差、有效点覆盖率和像素容差内成功率 |
| 检测指标用途 | 主要验收指标 | 辅助指标，解释目标是否找到及点位为何缺失 |
| 量化通过条件 | 框指标或框中心误差变化满足条件 | 关键点端到端表现及量化新增漂移均满足条件，检测退化同时可见 |

旧版数据的具体限制见[数据与输入预处理](02_21类目标数据与输入预处理.md)。本轮新语义是业务目标，候选数据是否逐类满足该目标仍需标注验收，不能仅从“两个点不重合”推断已经满足。

### 3.1 新版如何使用框

- GT 框严格读取标签中的 bbox 中心及宽高，不移动到 K1/K2，也不根据两个关键点重新生成一个框。
- 推理保留经过固定置信度阈值和 NMS 后的预测目标。NMS 是去除同一目标重复预测框的步骤；本轮首版不改成关键点 NMS。
- 评估进行同类一对一目标关联，再比较各自的 K1/K2。错误类别、重复预测和漏检分别统计，不能按真值挑选最接近的预测作为唯一输出。
- 框中心误差可以保留为检测诊断，但不能继续作为新版地理特征点定位精度的替代值。

### 3.2 新版如何定义 K1/K2

实施前按“数据版本、类别 ID、关键点编号”冻结语义说明，至少包括：点对应的地理特征、跨视角确认方法、可见与不可见示例、标注容差、K1/K2 顺序，以及训练翻转增强时的编号映射。

不能为了降低误差在评估时交换 K1/K2。若某目标只定义了一个有效点，应按合同标记另一个点无效，不能复制坐标来填满两个位置。现有文件不因此被原地修改；需要更正标注时发布新数据版本。

2026-10-28 复核的候选输入清单只记录了 `kpt_shape=[2,3]`，没有记录各类别的关键点名称和地理语义。这是阶段 P0 的待完成项。现有坐标可用于数值回归，但地理语义通过仍需单独验收。

### 3.3 如何比较新老模型

| 比较目的 | 旧模型如何评价 | 新模型如何评价 | 可得出的结论 |
|---|---|---|---|
| 历史复现 | 原数据、原框/点语义、原指标 | 使用新版自己的合同单独报告 | 各自结果可复现，不能据不同语义的分数直接排名 |
| 同一地理位置的业务对照 | 若业务同意，可把预测框中心明确记为该位置的代理估计 | 使用与该位置对应的 Kj 输出 | 在同图、同 GT 地理点和同坐标空间下，比较两种位置估计方法的误差 |
| 量化保真 | 旧模型在自己的合同内比较 PT 与量化版本 | 新模型在语义 KPTS 合同内比较 PT 与量化版本 | 分别判断量化保留了多少原模型能力 |

业务对照必须先指定目标地理点和旧输出的映射。不能把旧框中心直接叫作新版 K1/K2，不能把一个代理点复制成两个独立输出，也不能逐图挑更接近 GT 的位置作为旧模型结果。若旧模型没有可对应的输出，应标为“不适用”，而非给出虚假的同名关键点评分。

## 4. 标签解析与版本兼容方案

标准 YOLO Pose 的一行标签为：

```text
class cx cy w h K1x K1y K1v K2x K2y K2v
```

建议新增两种明确的解析格式，名称属于本计划拟定接口：

| 标签格式 | 框中心来源 | 宽高换算 | 关键点处理 |
|---|---|---|---|
| `legacy_pose_kpt_center_v1` | 按历史实现，K1 可见时替代 bbox 中心 | 保留已声明的历史 `label_wh_ref` 规则 | 保留旧任务的解释方式，用于历史复现 |
| `yolo_pose_normalized_v1` | 只用 `cx、cy` | `w×图像宽、h×图像高` | K1/K2 坐标和可见性独立解析 |

标准格式在图像宽高为 W、H 时，GT 框为：

```text
x1 = (cx - w/2) × W       y1 = (cy - h/2) × H
x2 = (cx + w/2) × W       y2 = (cy + h/2) × H
Kj = (Kjx × W, Kjy × H)
```

宽、高必须分别换算，不能把非正方形图片也按同一边长处理。标准格式不得隐式套用历史宽高参考值。

数据集登记格式，创建任务时把格式、类别表、关键点语义版本、坐标空间和指标定义快照到任务配置，并绑定哈希。任务执行各阶段读取同一份快照，不在阶段之间重新解释可变化的共享登记项。

既有任务先固定为历史解析版本，保留原结果。新创建的数据集或上传包必须明确声明格式；缺失或未知格式应在输入校验时失败，不按文件名、类别数或标签长度猜测。已有任务的缺失字段通过兼容迁移处理，不静默改成标准格式。

模型类别表与数据类别表要逐项核对。候选模型虽然也是 21 类，但不能因此沿用旧版的类别顺序、默认六类名称或保护类别清单；对应关系需在 P0 确认。

## 5. KPTS 主评价标准

### 5.1 坐标与匹配合同

本批首轮建议固定在 **net1280 输入像素坐标系** 中比较：使用已有 1000×1000 内容、四边 140 黑边的 Gray1 图像，不重复做缩放补边。训练 640 坐标系下的原始像素误差不得直接与此处数值比较。若另报源图坐标误差，必须保存并复用完整逆变换。

固定阈值像素评价首轮建议沿用已完成 500 张对照的设置：

| 项目 | 首轮建议 |
|---|---|
| 检测框置信度 | ≥0.25 |
| NMS IoU | 0.7；IoU 表示两框交并比 |
| 目标关联 | 同类别，按预测置信度顺序、IoU≥0.5，GT 与预测一对一 |
| GT 点资格 | visibility>0，包含 v=1 和 v=2；另可分列 v=2 可见点结果 |
| 预测点有效条件 | 置信度≥0.5，且坐标为有限值 |
| 点位对应 | 同一匹配目标内 K1 对 K1、K2 对 K2，不按最近距离交换 |

这些规则用于保留首轮对照的可解释性。若训练侧用于业务验收的像素指标采用其他关联或可见性规则，应在 P0 核对后统一冻结，并建立新的基线，不能只把两套报告都命名为“KPTS”就视为一致。

GT 的 visibility 是标注状态，预测点分数是模型置信度，两者含义不同，不能直接按同一个数值阈值解释。

框关联失败会影响点位覆盖率，即使某预测点碰巧接近真值，也不能在本指标中绕过实例身份直接算正确。标准 Pose mAP 使用自身的 OKS 匹配，需单列其定义，不混用上述匹配分母。

### 5.2 关键指标及分母

设某点预测与真值的坐标差为 dx、dy：

```text
L1 = |dx| + |dy|
L2 = sqrt(dx² + dy²)
```

| 指标 | 统计定义 | 新版用途 |
|---|---|---|
| K1/K2 L1、L2 | 对关联成功且两侧点有效的点，分别报均值、中位数、P95、最大值和样本数 | 主定位误差；L2 直接表达二维距离 |
| 有效点覆盖率 | 有关联、预测有效的 GT 合格点数 / 全部 GT 合格点数 | 防止漏掉难点后平均误差反而变好 |
| 像素容差内成功率 S@r | 有关联、预测有效且 L2≤r 的 GT 合格点数 / 全部 GT 合格点数 | 建议展示 r=1、2、5 px，漏检与无效预测均不能计成功 |
| 点位状态计数 | 分列漏检、类别/关联失败、预测点置信度不足、非有限坐标、GT 不可评点 | 解释误差与覆盖率的变化 |
| 检测 P/R/F1、TP/FP/FN | 保留固定检测阈值下的统计 | 辅助解释实例识别表现 |
| 框中心误差 | 仅对匹配框计算中心距离 | 保留检测诊断，不代替关键点误差 |
| Pose mAP/OKS | 如训练侧采用，则复用相同 OKS 公式、sigma、尺寸归一化及匹配设置 | 训练指标复现与补充展示 |

S@r 在本文明确采用“全部 GT 合格点”为分母，不能与其他项目在仅成功匹配点上计算的同名 PCK 混为一谈。没有合格 GT 点或没有可计算误差样本时显示“无样本”及 count=0，不用 0 px 或 100% 表示通过。

所有主指标至少按总体、类别、K1/K2 拆分，同时展示难度、目标尺寸及点位可见性分组。整体均值不能掩盖某个地标或某个关键点失效。

两个地理关键点不应直接套用人体 17 点的 OKS 参数。只有冻结训练侧实际使用的定义后，才可以声称与训练评价一致。

### 5.3 旧页面指标如何处理

当前平台 `pixel_error` 实际统计检测框中心误差；升级后旧字段继续保持原意，页面明确标注“框中心误差”。关键点使用独立字段和主面板，不能直接把旧数值改名为关键点误差。

当前平台 `mAP` 是逐类 Precision×Recall 的平均，并非标准 COCO mAP 或 Pose mAP。兼容旧报告时保留原始字段，但页面标明“历史代理分数”。若新增标准 Pose mAP，使用独立字段并附指标定义。

### 5.4 网页指标计算说明（2026-10-29 更新）

当前网页的 44 条说明与 `apps/web/metric_help.json` 同源；[本轮指标说明源文件](../../../task-artifacts/20261029-metrics-display-fix/source/apps/web/metric_help.json)已冻结。悬停范围包含指标名称、图标与数值单元格，另有可展开的完整说明表；键盘聚焦或点击也能查看。

记 N 为当前范围内全部 GT v=1/2 点数，M 为其中获得有效预测的点数，C 为前后阶段均有效的共同点数。范围可为总体、类别、K1/K2 或分组，各自独立计算分母。单位为 net1280 像素，不是地面米数。

**关键点定位、分母与分组**

| 指标 | 计算方式 | 统计目的 | 分母或边界 |
|---|---|---|---|
| 点位 | 总体合并当前范围的 K1/K2；K1 仅对 K1，K2 仅对 K2。 | 区分整体表现与某个编号点失效。 | 不为降低误差交换点位。 |
| 合格 GT | N = GT 可见性 v=1 或 v=2 的关键点数量。 | 给出本次应评价的点数，也是覆盖率和 S@r 的固定分母。 | 包含目标未关联的点；v=0 不进入 N。 |
| 有效预测 | M = 在 N 中，目标同类一对一 IoU≥0.5 关联成功、预测点分数≥0.5 且坐标有限的点数。 | 统计可计算定位误差的点数。 | 有效不代表定位准确；偏差很大的点仍可能有效。 |
| 覆盖率 | 覆盖率 = M / N × 100%。 | 衡量应识别的点有多少获得有效预测，防止漏掉难点后平均误差反而变好。 | 目标未关联和低分/无效预测留在分母；N=0 时无样本。 |
| L1 均值 | 每点 L1=\|预测x−GT x\|+\|预测y−GT y\|；对 M 个有效点取算术平均。 | 衡量横向与纵向绝对偏差之和，单位 px。 | 仅统计有效点；M=0 为无样本。 |
| L2 均值 | 每点 L2=√[(预测x−GT x)²+(预测y−GT y)²]；对 M 个有效点取算术平均。 | 衡量平均二维定位距离，越小越好。 | 单位为 net1280 图像像素；漏点不进入平均，必须同时看覆盖率。 |
| L2 中位数 | 把 M 个有效点的 L2 排序，取第 50 百分位；偶数个样本取中间两项平均。 | 反映典型点误差，减少少数极端误差对均值的影响。 | M=0 为无样本；不能替代尾部误差。 |
| L2 P95 | 有效点 L2 升序排列，取 95% 分位；索引 t=(M−1)×0.95，在相邻两项间线性插值。 | 观察较差一端的定位误差，约 95% 的有效点误差不超过该值。 | 只代表有效点，不代表全部 GT；M=0 为无样本。 |
| L2 最大值 | M 个有效点的 L2 中的最大值。 | 暴露最严重的单点定位偏差，便于追查异常图片。 | 对极端值敏感；M=0 为无样本。 |
| L2 均值 / P95 | 左值是有效点 L2 的算术平均，右值是其按 (M−1)×0.95 线性插值得到的 95% 分位。 | 同时观察平均定位距离和尾部误差。 | 单位 px；仅针对有效点，无有效点时无样本。 |
| S@1px | 有效且 L2≤1 px 的 GT 点数 / N × 100%。 | 衡量全部应评价点中达到 1 像素精度的比例。 | 漏点、低分和无效预测均不成功；不是只在已匹配点上计算。N=0 为无样本。 |
| S@2px | 有效且 L2≤2 px 的 GT 点数 / N × 100%。 | 衡量全部应评价点中达到 2 像素精度的比例。 | 边界包含 2 px；N=0 为无样本。 |
| S@5px | 有效且 L2≤5 px 的 GT 点数 / N × 100%。 | 衡量端到端定位成功比例，同时反映漏点和偏差。 | 1/2/5 px 是报告分档，尚未自动作为业务通过门槛；N=0 为无样本。 |
| 点位状态 | 对每个 GT 点位分别计数：valid、unmatched_target、low_confidence、nonfinite_prediction、gt_not_evaluable。 | 解释覆盖率不足来自目标未关联、点分数不足还是非法坐标。 | v=0 属于不可评价 GT，不进入 N；其他合格但失败的点仍进入 N。 |
| 可见性 | 按 GT 的 v=0/1/2 分组；v=1/2 合格，v=0 不计定位评价。 | 区分不同标注可见性下的表现。 | GT 可见性是标注状态，预测点分数是模型输出，含义不同。 |
| 难度 | 按文件名中的 easy/medium/hard/extreme 分组，未匹配到的归 unknown。 | 检查困难样本是否被整体平均掩盖。 | 分组来自已有命名，不是评价器重新判断图像难度。 |
| 框面积 | GT 框面积 / 输入图像面积：<1%、1%至<10%、≥10% 三组。 | 检查不同目标尺寸上的关键点表现。 | 同一组中的覆盖率、成功率仍用本组全部合格 GT 点作分母。 |

**阶段间比较**

| 指标 | 计算方式 | 统计目的 | 分母或边界 |
|---|---|---|---|
| 共同有效 / 合格 GT | 左值 C 为前后阶段对同一图、同一 GT 对象、同一 K1/K2 均有效的点数；右值为固定 N。 | 说明漂移统计覆盖了多少点，防止只比较保留下来的容易点。 | 两阶段合同及完整 GT 身份必须一致；无共同有效点时漂移无样本。 |
| 坐标漂移均值 / P95 / 最大值（px） | 在 C 上计算 √[(后阶段x−前阶段x)²+(后阶段y−前阶段y)²]，再报均值、95% 分位及最大值。 | 衡量导出、量化或输入回环改变了多少预测坐标。 | 漂移比较预测与预测，不是预测与 GT；小漂移不保证原模型定位准确。 |
| 同集合 GT 平均误差变化（px） | 仅在共同有效集合 C 上：后阶段对 GT 的平均 L2 − 前阶段对 GT 的平均 L2。 | 在完全相同的点集上观察定位误差增减。 | 正值变差、负值变小；不能用两阶段各自不同有效集合的均值直接相减。 |
| 覆盖率变化（百分点） | (后阶段 M/N − 前阶段 M/N) × 100。 | 发现新增漏点或有效点恢复。 | 90%→89% 为 −1 个百分点，不是 −1%；分母 N 固定。 |
| S@5px 变化（百分点） | (后阶段 5px 内成功点数/N − 前阶段 5px 内成功点数/N) × 100。 | 观察全部应评价点的端到端精度变化。 | 正值成功率提高，负值下降；N=0 为无样本。 |
| 排除点的状态变化 | 对 GT 合格但不属于共同有效集合 C 的点，统计前阶段状态 → 后阶段状态的数量。 | 揭示漂移统计排除了哪些点及原因。 | 例如 valid → low_confidence 表示新增点位分数不足，不能当作零漂移。 |

**检测辅助、样例与全量问题诊断**

| 指标 | 计算方式 | 统计目的 | 分母或边界 |
|---|---|---|---|
| Precision | TP / (TP+FP)。TP 为同类框一对一 IoU≥0.5 关联成功数，FP 为未成功关联的预测框数。 | 衡量预测目标中有多少检测正确。 | 属于框检测指标，不能说明 KPTS 定位准确；历史实现分母为 0 时返回 0。 |
| Recall | TP / (TP+FN)，FN 为未被正确关联的 GT 对象数。 | 衡量实际目标有多少被检出。 | 这是对象召回率，不是关键点覆盖率；历史实现分母为 0 时返回 0。 |
| F1 | 2×Precision×Recall / (Precision+Recall)。 | 综合观察框检测的精确率与召回率。 | 不能替代关键点误差；现有实现 P+R=0 时返回 0。 |
| 历史代理分数（逐类 P×R 均值） | 对 0..nc−1 各类计算 Precision×Recall，再对全部 nc 类求平均。 | 保留旧报告的兼容比较。 | 不是标准 COCO mAP 或 Pose mAP；现有实现无样本类按 0 参与均值。 |
| 框中心误差（mean px） | 对匹配成功框，求预测框中心与当前解析 GT 框中心的欧氏距离，再取均值。 | 诊断检测框的位置偏移。 | 不是 K1/K2 误差；历史标签解析可能用 K1 代理框中心。旧字段保留无匹配时 0/count=0 的行为。 |
| 问题图 (ClassErr / FP / FN) | 分别统计已导出问题样例中的类别错误、误检、漏检分组图数；受样例导出上限限制。 | 定位可人工查看的检测问题样例。 | 不是全部问题图数或 TP/FP/FN 对象总数；同一图可属于多个组，不应相加当作不同图片数。 |
| ClassErr 样例图数 | 已导出的类别错误样例分组中的图片数。 | 说明当前可查看多少张分类错误样例。 | 受样例导出上限限制，不是全测试集分类错误对象总数。 |
| FP 样例图数 | 已导出的误检样例分组中的图片数。 | 说明当前可查看多少张误检样例。 | 受样例导出上限限制；同一图可能也含漏检或类别错误。 |
| FN 样例图数 | 已导出的漏检样例分组中的图片数。 | 说明当前可查看多少张漏检样例。 | 受样例导出上限限制，不是全部漏检对象数。 |
| 单图 FP 诊断 | 该样例图中，另行识别并剔除 ClassErr 配对后的剩余误检框数。 | 诊断该图还存在多少其他误检。 | 主检测 Precision 的 FP 仍按原同类匹配计算，不因样例分组而改变。 |
| 单图 FN 诊断 | 该样例图中，另行识别并剔除 ClassErr 配对后的剩余漏检 GT 框数。 | 诊断该图还存在多少其他漏检。 | 主检测 Recall 的 FN 不因样例分组而改变。 |
| 实例数（框） | 测试标签中该类别的 GT 对象行数。 | 了解每类目标的样本量，判断细分指标是否样本过少。 | 对象数不是关键点数；一对象有 K1/K2 两个点位，是否合格还需看 v。 |
| 含该类的图数 | 至少包含一个该类别 GT 对象的测试图片数。 | 了解该类别覆盖了多少张图。 | 一图多目标仍只计一张；一图可能同时含多类。 |
| TP | 同类别预测框与 GT 按置信度顺序做 IoU≥0.5 的一对一关联，成功关联的对象数。 | 统计正确检测对象数。 | TP 不表示对应关键点已达到像素精度要求。 |
| FP | 未与同类 GT 成功一对一关联的预测框数。 | 统计误检、重复预测或错误类别预测。 | 样例面板可能将其中类别错误另外展示；不改检测主指标的对象计数。 |
| FN | 没有同类预测框成功一对一关联的 GT 对象数。 | 统计漏检或类别/关联失败对象。 | 漏检对象数与未关联关键点数不是同一指标。 |
| ClassErr | 问题图诊断中，将原本未匹配的预测和 GT 按重叠框 IoU≥0.5 再关联，类别不同的记为类别错误。 | 区分识别了区域但分类错误的情况。 | 仅用于问题样例诊断，主检测统计中错误类别仍会造成 FP/FN。 |
| ClassErr（全量对象） | 读取全部保存预测；先同类置信度顺序一对一匹配，再将剩余预测与 GT 中 IoU≥0.5、类别不同的框按 IoU 降序一对一配对。 | 统计全测试集中区域重叠但类别错误的对象配对数。 | 每个配对已各自计入主检测 FP 和 FN，不能额外相加；缺少完整预测时显示未统计。 |
| 全量类别错误图数 | 全部保存预测中，至少含一个 ClassErr 配对的不同图片数。 | 反映全测试集有多少张图片出现类别错误。 | 该数字不受展示上限影响；每组只取前 10 张图供查看。 |
| 全量误检图数 | 全部保存预测中，主检测 FP>0 的不同图片数，包含类别错误造成的 FP。 | 统计全测试集的误检覆盖了多少张图。 | 图数不是误检对象数；同一图也可能含漏检或类别错误。 |
| 全量漏检图数 | 全部保存预测中，主检测 FN>0 的不同图片数，包含类别错误造成的 FN。 | 统计全测试集的漏检覆盖了多少张图。 | 全量数量与实际展示的前 10 张样例数量分开报告。 |

**第 13 节完整 500 张 PT 的计算例子**：N=1157、M=1065，覆盖率为 `1065/1157=92.05%`；其中 1010 点有效且 L2≤5 px，所以 S@5px 为 `1010/1157=87.29%`，不能改用 1065 作分母。有效点中 55 点超过 5 px；另有 90 点目标未关联、2 点分数不足，后二者保留在成功率分母。2.22 px 平均 L2 只针对 1065 个有效点，因此需要与覆盖率同时阅读。

例如 GT=(100,200)、预测=(103,204)，L1=7 px、L2=5 px；该点达到 S@5px，未达到 S@1px/S@2px。如果点没有有效预测，不能用 0 px 填补误差，但应在固定分母的成功率中计失败。

阶段间漂移与 GT 定位误差不同：前后预测即使都错在同一位置，漂移仍可能为 0。阶段均值差也必须在共同有效集合 C 上计算；漏掉的点另看覆盖率和状态变化。90%→89% 是下降 1 个百分点。

## 6. 量化前后如何使用同一标准

按以下链路逐层比较，所有阶段固定同一测试清单、GT 解析、关键点身份、坐标空间和指标定义：

```text
A：PT FP32
→ B：导出的 FP16 ONNX
→ C：量化 ONNX
→ D：FPGA 输入格式的软件回环
→ E：真实 FPGA 回传结果（另行取得硬件证据）
```

| 比较 | 主要回答的问题 |
|---|---|
| A 对 GT | 模型在本批输入上的原始关键点定位能力 |
| B 对 A、GT | 导出及 FP16 转换是否改变了点位或识别能力 |
| C 对 B、GT | 在同等浮点基线上，权重量化新增了多少退化 |
| C 对 A、GT | 最终软件交付相对 PT 的总变化 |
| D 对 C、GT | 输入格式转换和回环带来多少变化 |
| E 对 C/D、GT | 硬件实现、数值和接口是否对齐 |

必须同时给出两类结果：

1. **业务定位结果**：每阶段相对 GT 的误差、覆盖率、S@r 和检测计数。
2. **量化新增漂移**：在两个阶段共同关联到同一 GT、同一关键点身份且均有效的集合上，计算两阶段预测坐标的距离，并报告该集合大小及被排除原因。

不能只比较两个阶段各自平均误差的差值，因为其有效样本集合可能不同。也不能只比较共同成功点，忽略量化新增的漏检或低置信度点。

首轮先保持现有量化配置和模型输出结构，补齐 KPTS 解析与验收。评价标准改变不会自动改善模型数值精度；本次 GT/指标适配原则上可以复用已有 PT 和 ONNX，不必为修正统计立即重新量化。

若后续要根据 KPTS 指标选择敏感层、精度类型或量化策略，则属于第二轮优化：需要独立带标签的开发验证集，固定策略后再测测试集。标定集仍可无标签；若改为需要监督信号的训练方法，则须另行准备相应训练数据。

## 9. 验收与回归要求

### 9.1 必须通过的功能回归

1. 标准格式下，只改变 K1/K2 坐标不能改变 GT bbox；历史格式按原合同精确复现。
2. 覆盖 K1 偏离中心、K1/K2 不重合、不可见点、多目标、空标签、非方形图像和非法值。
3. 同一标签在 PT、ONNX、输入回环、GT JSON 和可视化中得到相同的 GT 语义及坐标。
4. 关键点编号、类别顺序或坐标合同不匹配时，在执行前明确失败；不自动交换点位或复用默认类别名。
5. 使用第 12 节绑定身份的同一批已保存预测，标准 GT 精确复现 TP/FP/FN=553/85/90，历史 GT 精确复现 215/423/428。此检查无需 GPU 推理。
6. 固定预测、GT 及规则重复统计时，各点数量、分母、误差和匹配结果一致；无样本和无效值不被记为成功。
7. 500 张可视化逐文件可读、图像与标签一一对应，抽查覆盖正确定位、偏移、漏检、多目标及不可见点。
8. 历史模型/数据在旧合同下保持原统计，已发布模型、原始图、标签、报告和 ZIP 哈希不因升级而改变。

### 9.2 待评审的精度门槛

业务绝对定位要求尚未给出，本计划不把既有 PT 数值直接当作合格上限。1/2/5 px 首先是报告分档，正式通过门槛需在 P0 确认。

可将下面数值作为首轮 **B→C 量化退化门槛的讨论起点**，它们不是已批准标准，也不代表已经通过：

| 项目 | 建议讨论值 | 检查范围 |
|---|---|---|
| 对 GT 的共同有效点 L2 均值增加 | ≤0.5 px | 分 K1/K2，对同一批 GT 点比较 |
| 同集合 L2 P95 增加 | ≤1.0 px | 同时保留原误差分布和异常样本 |
| 全部合格 GT 点的有效覆盖率下降 | ≤1 个百分点 | 分 K1/K2，并检查类别分组 |
| S@5px 下降 | ≤1 个百分点 | 分母固定为全部 GT 合格点 |
| 两阶段预测坐标漂移 | 报均值、P95、最大值；限值待定 | 共同关联目标及相同关键点身份 |
