## 如何理解本资料包

当前资产位置、完整哈希及覆盖范围仍由[平台 01](../../docs/platform/01_NAS备份与环境恢复.md)维护；本目录组织阅读和恢复路线。历史报告保持原位置、原内容；复制到这里的九份文件也保持原字节，不作为第二套持续修改的实现或证据。以后需要更新脚本，应在原位置按独立任务维护，再创建新的有日期快照与来源清单。

本目录没有镜像、大数据集和完整 NAS 元数据，也不能独立于项目链接充当完整离线恢复包。原始 Dataset 的源文件清单、分片清单和运行日志，镜像的详细 records，以及 PT 临时备份的 manifest，仍需从各原记录指定位置获取；缺少材料不能假定已验证。[历史清单](HISTORY.md)列出了具体证据边界。

**本地文件与 GitHub 不同：** 仓库规则排除 `.py`、`.zip` 等文件。本目录中的脚本快照和修改前 ZIP 在本机存在，但不会随普通 Git 克隆分发；本轮没有修改忽略规则、提交或推送。需要交给别人时，应另行制作带哈希的资料包，不能仅发送 GitHub 链接。规则见[版本管理](../../docs/VERSION_CONTROL.md)。

本目录的当前字节身份纳入 [rebuild 的 20261110 路径复查版本清单](../SHA256SUMS.20261110-nas-paths)。历史清单保留；本地清单和 NAS 路径存在性检查均不等于备份内容或完整恢复已经验收。
